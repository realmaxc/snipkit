# Changelog

All notable changes to this project are documented here. The format is based on
[Keep a Changelog](https://keepachangelog.com/en/1.0.0/), and the project aims
to follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

## [0.1.0] - 2026-07-12

### Added
- Fuzzy `search` with acronym-friendly scoring.
- `pick` command with `fzf` support and a numbered fallback.
- SQLite backend alongside the default JSON store.
- Clipboard integration and shell key-binding examples.
- `import`/`export` as JSON, and a `tags` overview command.
- Id-prefix lookups for `get`, `copy`, `edit`, and `rm`.

## [0.0.1]

### Added
- Initial prototype: JSON store and the first `add`/`list`/`get` commands.
